# xiaohuasheng105.github.io

xiaohuasheng105의 개인 블로그입니다. GitHub Pages를 사용하여 호스팅됩니다.

## 구조

- `index.html`: 메인 페이지
- `about.html`: 소개 페이지
- `contact.html`: 연락처 페이지
- `posts/`: 블로그 포스트들
- `css/style.css`: 스타일시트
- `js/script.js`: 자바스크립트

## 사용법

1. 이 레포지토리를 클론합니다.
2. 로컬에서 파일을 편집합니다.
3. 변경사항을 커밋하고 푸시합니다.
4. GitHub Pages에서 자동으로 배포됩니다.
